## NoHaser

This anticheat will follow the [Minecraft Packets Protocol 776 (26.2)](https://minecraft.wiki/w/Java_Edition_protocol/Packets). It is largely inspired by (and built from) its sister anticheat made for Minecraft 1.8.8 - [NoHaserBenis](https://github.com/Poooooooooolch/NoHaserBenis).

Although we will convert packet classes into our own classes, we will be using [PacketEvents 2.14.0](https://github.com/retrooper/packetevents/releases/tag/v2.14.0) to listen to packets with Paper as our server platform on 26.2.
