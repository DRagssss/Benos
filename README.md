## NoHaser

This anticheat currently follows the [Minecraft Packets Protocol 776 (26.2)](https://minecraft.wiki/w/Java_Edition_protocol/Packets). It is largely inspired by (and built from) its sister anticheat made for Minecraft 1.8.8 - [NoHaserBenis](https://github.com/Poooooooooolch/NoHaserBenis).
